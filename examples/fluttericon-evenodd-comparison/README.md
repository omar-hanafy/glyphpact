# FlutterIcon.com even-odd comparison

This small Flutter app preserves the inputs and outputs behind the public
GlyphPact comparison. It renders each fixture in three ways inside the same
widget tree:

1. the exact source SVG through `flutter_svg`;
2. the TTF exported by FlutterIcon.com on 2026-07-26;
3. the OTF/CFF generated by GlyphPact 1.0.1.

All three source files are valid, single-path SVGs with
`fill-rule="evenodd"` and `clip-rule="evenodd"`.

In this export, the FlutterIcon font renders without three source cutouts:

- the location pin's centre hole;
- the chat bubble's third dot;
- the envelope's interior cutout.

GlyphPact preserves all three in the same Flutter application. This result is
limited to these fixtures and this dated export. It is not a claim about every
even-odd SVG or every FlutterIcon.com export.

## Reproduce

The preserved environment is documented in
[`evidence/ENVIRONMENT.md`](evidence/ENVIRONMENT.md), and hashes are recorded in
[`evidence/SHA256SUMS`](evidence/SHA256SUMS).

From this directory:

```bash
flutter pub get
dart analyze
flutter test
flutter run -d macos
```

The widget test checks the comparison structure and labels. The native capture
in `evidence/comparison.png` is the visual reference.
`evidence/comparison-web.png` is the same capture re-encoded without the macOS
display profile so browsers render it consistently, and is the version served
on the website. `evidence/comparison-source-2x.png` preserves the original 2x
CleanShot.

## Regenerate the article and website graphics

`test/article_graphics_test.dart` builds the comparison table at an 800 x 640
logical canvas and the cover at a 1000 x 420 logical canvas. Flutter renders
both at 2x pixel density into lossless PNG goldens.

```bash
flutter test test/article_graphics_test.dart --update-goldens
flutter test test/article_graphics_test.dart
```

The expected files are:

```text
test/goldens/glyphpact-dev-comparison-v3-2x.png  1600 x 1280
test/goldens/glyphpact-dev-cover-2x.png          2000 x 840
```

The website uses HTML for the detailed comparison and loads the exact source
SVGs, FlutterIcon TTF, and GlyphPact OTF directly. The goldens are retained for
article covers, sharing, and pixel-level regression.

## Verify the historical GlyphPact output

Install GlyphPact 1.0.1, then run:

```bash
glyphpact --config tool/glyphpact_icons.json --check
```

The strict report records:

```text
3 discovered
3 lossless
0 approximated
0 skipped
0 issues
```

Do not regenerate these historical artifacts with a newer GlyphPact version
and leave the screenshot labelled 1.0.1. A new experiment needs a new capture,
report, hashes, and dated note.
